# AI 工具提示词追溯记录（prompt 目录）

## 一、目录用途

按照课程 vibe coding 开发方法与课程设计要求，本目录用于**记录开发全过程中与 AI 工具的交流记录**（提示词、交互过程、关键决策），形成可追溯的 AI 协作开发档案。

## 二、收录内容

- 每个开发阶段与 AI 工具（豆包、通义灵码等）的对话/提示词记录（JSON 格式）
- 原始需求、任务拆解、约束说明、验收标准
- 关键设计决策与理由
- 各阶段交付物清单

## 三、更新规范

1. **每阶段必更**：选题与方案设计、数据准备、模型开发、后端开发、前端开发、集成调试、成果整理各阶段完成后，均需在本目录新增/更新对应阶段记录。
2. **及时备份**：在 AI 上下文压缩（会话轮次过多）前，必须先将当前会话的提示词记录导出备份到本目录，防止丢失。
3. **命名规范**：按阶段命名，如 `stage2_data_preparation.json`，并在 README 进度表中登记。
4. **格式规范**：统一使用 UTF-8 编码 JSON 文件，结构参照已有记录。
