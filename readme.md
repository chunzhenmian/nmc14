# 工业燃气轮机氮氧化物排放预测与运行参数智能优化系统

> 大三课程设计 · 智能制造工程专业
> 开发方法：vibe coding 开发方法 + Git 版本控制

## 一、项目简介

面向工业燃气轮机电站的运行优化与排放管控场景，构建完整 B/S 架构的可运行演示系统，实现三大核心功能：

1. **排放浓度精准预测** —— 基于运行参数，采用 XGBoost 回归模型预测 NOx、CO 排放浓度与机组能量产出
2. **运行参数智能寻优** —— 采用粒子群优化算法（PSO），以排放达标为约束、最大化机组能量产出为目标，自动寻优关键运行参数
3. **工况异常早期预警** —— 采用孤立森林算法，基于正常工况数据识别工况异常与排放异常

## 三、数据来源

本项目使用 **UCI 燃气轮机 CO 与 NOx 排放数据集**（Gas Turbine CO and NOx Emission Data Set）：

- **官方链接**：https://archive.ics.uci.edu/dataset/551/gas+turbine+co+and+nox+emission+data+set （已验证有效，HTTP 200）
- **DOI**：https://doi.org/10.24432/C5WC95
- **数据规模**：土耳其某燃气电站 2011-2015 年连续运行监测数据，共 36733 条小时级样本，无缺失值
- **字段构成**：9 项运行参数（环境温度/压力/湿度、压气机出口压力、涡轮进口/排气温度、能量产出等）+ CO、NOX 排放浓度

数据已随仓库提交至 `data/raw/`，字段含义、引用方式详见 [`data/README.md`](data/README.md)。

## 四、数据预处理

预处理程序位于 `scripts/preprocess.py`，运行方式：

```bash
python scripts/preprocess.py
```

### 4.1 预处理流程

1. **数据合并**：合并 2011-2015 五个年度 CSV，添加 `year` 列
2. **质量检查**：缺失值检查（结果：0 缺失）、重复行检查、物理合理性检查（压力/温度/排放浓度为正）
3. **去重清洗**：删除 7 条重复样本（位于 2014 年数据）
4. **数据划分**：按年份划分训练/验证/测试集
   - 训练集：2011-2013 年（22191 条）
   - 验证集：2014 年（7151 条）
   - 测试集：2015 年（7384 条）
   - *遵循 UCI 官方建议的"前三年训练、后两年测试"协议，避免随机切分导致时序信息泄漏*
5. **特征标准化**：使用 StandardScaler 仅在训练集上拟合，保存 scaler 供模型开发阶段复用

### 4.2 预处理产物（data/processed/）

| 文件 | 说明 |
| :--- | :--- |
| `gt_combined.csv` | 合并去重后的全量数据（36726 条，含 year 列） |
| `train.csv` / `val.csv` / `test.csv` | 原始数值的三分集（特征 + 目标 + year） |
| `train_scaled.csv` / `val_scaled.csv` / `test_scaled.csv` | 标准化特征版三分集 |
| `scaler.joblib` | 特征标准化器（模型开发阶段复用） |
| `preprocess_report.json` | 预处理报告（数据量、清洗记录、统计信息） |
